# Fact-check memo, wave 2, filed 2026-09-27

Role: Fact-Checker (Quality Monitor).

Method and limits. WebSearch worked this cycle (about 25 queries); WebFetch was blocked by the egress proxy for every host tried (improbable.com, science.nasa.gov), so no primary paper or press release was opened. Verification rests on search-result text from named outlets, matched against each other. "Two sources" means two separately authored outlets; where both derive from the same press release this is noted. The GitHub code-search route from 05-fact-check.md was not needed. No fact below was invented; "unverified" marks what could not be confirmed. Standing request: add nature.com, science.org, aanda.org, academic.oup.com, improbable.com and science.nasa.gov to the allowed domains so a paper can be opened before publication.
